# Miami Redesign.ai

> AI-Powered website redesign service for Miami businesses.

## Quick Start

```bash
cd miamiredesign
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Project Status

MVP in progress — initial site structure and components complete.

## Stack

* **Framework**: Next.js 14 (App Router)
* **Styling**: Tailwind CSS
* **Language**: TypeScript
* **Icons**: Lucide React
