# Miami Redesign.ai

> AI-Powered website redesign service for Miami businesses.

> **Static HTML site** — deployed to GitHub Pages. No build step, no server required.

## Quick Start

1. Clone the repo:
   ```bash
   cd miamiredesign
   ```

2. Open `index.html` in a browser to preview locally, or push to GitHub to see it live.

## Project Status

MVP complete with hero, tools, services, and industries sections.

## Tech Stack

* **HTML** — Semantic markup
* **Tailwind CSS** — via CDN (no build step)
* **JavaScript** — Vanilla JS for interactivity
* **Deployed to** — GitHub Pages
